# Running Python online

Use this when the computer doesn't have Python.

## 1. Pick a site

- [OneCompiler](https://onecompiler.com/python): simple, and you enter input before running.
- [Programiz](https://www.programiz.com/python-programming/online-compiler/): lets you type input while it runs.
- [Python.org shell](https://www.python.org/shell/): a quick REPL for testing one line at a time.

## 2. Just paste your code

Unlike C#, there's no template. Your file works as it is.

## 3. Typing input

On OneCompiler, your program can't stop and wait for you to type. Put your answers in the **STDIN** box before pressing Run, one per line:

```
Alex
95
```

For games like Day 4's guessing game, use Programiz, which does wait for input, or finish it on your laptop.

## Differences from your laptop

| On your laptop | On these sites |
|---|---|
| You run `python file.py` | You press Run |
| You can `pip install` packages | Only the standard library, usually |
| Files you write stay on disk | Files may disappear when you close the tab |

Days 1–18 work fine online. From Day 19, you need packages, so use your laptop.

Remember to copy your code somewhere before closing the tab, or it may be lost.
